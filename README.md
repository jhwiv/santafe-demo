# Santa Fe Itinerary — Case Study

Anonymized portfolio version of a mobile-first luxury travel companion app built by Barrier Island Digital. The live client app remains separate and private.

## Structure

- `index.html` — single-page app with sticky tab nav, condensed view, per-day panels (with weather cards), restaurant modals
- `styles.css` — editorial cream/paper theme with terra + gold accents
- `img/hero.png` — Santa Fe adobe + bell-tower hero image
- `CNAME` — custom domain pointer for GitHub Pages

## Local preview

```
python -m http.server 8000
# open http://localhost:8000
```

## About this demo

All personal identifiers (traveler name, agency, booking references, e-ticket, seat assignments) have been redacted. Public information (restaurants, public phone numbers, generic itinerary structure) is preserved to showcase the build.
